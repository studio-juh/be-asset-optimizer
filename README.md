# Be Asset Optimizer

Blenderへ持ち込む前の画像・テクスチャ・3Dアセットを、ひとつの画面でまとめて整えるWindows向けデスクトップアプリです。

複数画像の軽量化、リサイズ、PNG-8減色、ノーマルマップ生成、2×2テクスチャアトラス作成、FBX / GLBの簡易確認に対応します。画像処理はPC内で完結し、素材そのものを外部サービスへ送信しません。

> 現在のバージョン: 0.6.1 / Windows x64

## 主な機能

### 画像最適化

- 画像やフォルダーをドラッグ＆ドロップして一括処理
- PNG（既定）/ WebP / JPEG出力
- 最大幅・最大高・倍率を指定したリサイズ
- 高品質補間とピクセルアート向け補間
- PNG-8（16〜256色）、PNG-24、PNG-32、グレースケール
- ディザリング、WebP / JPEG品質、PNG最適化強度の調整
- 元画像より大きくなった場合の自動スキップ
- サムネイル、処理状況、変換前後の寸法・容量を一覧表示

### AI復元

- Real-ESRGAN / RealESRNetを利用したローカル画像復元
- 元の寸法、2倍、4倍出力
- 自然さを重視するモードと、細部を強調するモード
- 復元強度、分割品質、タイル境界ブレンドを調整可能
- 必要なAIコンポーネントだけを初回利用時に追加
- 約61 MBを4分割で並列ダウンロードし、SHA-256検証後に約70 MBを保存

### ノーマルマップ

- 高さマップや画像の明度から一括生成
- Blender向けOpenGL（+Y）とDirectX（-Y）を切り替え
- 強さ、高さレベル、Gチャンネル反転、長辺リサイズ
- 長方形画像を高さ0で正方形へ補完

### テクスチャアトラス

- 4枚の画像を2×2のアトラスへ結合
- 任意の枠へのドロップ、ドラッグによる入れ替え
- 長方形画像を引き伸ばさず正方形セルへ補完
- 1枠あたり256〜4096 pxまたは自動解像度

### 3Dプレビュー

- FBX / GLBを読み込み、形状・マテリアル・アニメーションを確認
- FBXと同じフォルダー以下から相対テクスチャを探索
- GLB内の埋め込み画像を表示
- ワイヤーフレーム、グリッド、自動回転、回転リセット

## 動作環境

- Windows 10 / 11 64-bit
- Microsoft Edge WebView2 Runtime
- 画面解像度 960 × 640以上
- AI復元のみ: Vulkan対応GPU、最新のGPUドライバー、初回追加時のインターネット接続
- AIコンポーネント保存用の空き容量: 約70 MB

通常のWindows 10 / 11にはWebView2 Runtimeが導入されています。AI復元以外の機能はAIコンポーネントやGPUを必要としません。

## 導入方法

### セットアップ版（推奨）

1. `Be Asset Optimizer_0.6.1_x64-setup.exe` を実行します。
2. 画面の案内に従ってインストールします。
3. スタートメニューまたはデスクトップのショートカットから起動します。

現在の配布物にはコード署名がないため、Windowsの発行元確認やSmartScreenが表示される場合があります。入手元とファイル名を確認したうえで実行してください。

### ポータブル版

1. `Be_Asset_Optimizer_0.6.1_windows_x64_portable.zip` を展開します。
2. フォルダー内の `Be Asset Optimizer.exe` を起動します。
3. アプリを移動するときは、フォルダーごと移動します。

インストールやショートカット作成は不要です。AIコンポーネントはEXE横の `components` フォルダーへ保存されます。

## 基本的な使い方

1. 上部のタブまたは「機能」メニューから目的の機能を選びます。
2. ファイル／フォルダーを画面へドロップするか、`Ctrl+O`で選択します。
3. 左側で出力先と変換設定を指定します。
4. 一覧を確認して変換を開始します。
5. 完了した行の「開く」から出力ファイルを表示します。

元ファイルは上書きしません。出力先を指定しない場合は、入力元の近くに機能別の出力フォルダーを作成します。

## 対応形式

| 用途 | 対応形式 |
| --- | --- |
| 画像入力 | PNG / JPEG / JFIF / WebP / HEIC / HEIF / BMP / TIFF / GIF / TGA / DDS |
| 画像最適化の出力 | PNG / WebP / JPEG |
| 3Dプレビュー | FBX / GLB |
| FBXの外部テクスチャ | PNG / JPEG / WebP / BMP / TGA / DDS |

HEIC / HEIFはWindowsの追加コーデックなしで読み込めます。GIFは先頭フレームを静止画として使用します。

## AI復元について

AI復元タブで「AI機能を追加」を押すと、専用のGitHub Releaseから必要な実行環境とモデルを取得します。ZIP全体と各ファイルのSHA-256が一致した場合だけ保存します。専用配布を取得できない場合は、Real-ESRGAN公式Releaseへ自動的に切り替えます。

追加後の画像処理はローカルで実行され、PythonやCUDA、継続的な通信は不要です。通常版はWindowsのユーザーデータ領域、ポータブル版はEXE横へ保存します。追加データはAI復元画面の折りたたみ欄から削除できます。

AI処理は元画像に存在しない細部を推測するため、画像によっては模様・ぼかし・タイル状の違和感が生じます。ノーマル、粗さ、金属、マスクには直接適用せず、必要なら復元したアルベドから作り直してください。

## 3Dプレビューについて

3Dプレビューは、Blenderへ持ち込む前の形状とテクスチャ参照を簡易確認する機能です。モデルの編集やFBX / GLBの再出力は行いません。

FBXではモデルと同じフォルダー以下を最大5階層まで探索します。FBXとテクスチャの相対的なフォルダー構成を保ってください。形式やマテリアル設定によっては、元ソフトと完全に同じ見た目にならない場合があります。

## プライバシーと安全性

- 入力画像や3Dモデルを外部へアップロードしません。
- 変換処理はPC内で実行します。
- ネットワーク通信はAIコンポーネントの追加時だけ使用します。
- AIコンポーネントは保存前にSHA-256で検証します。
- 元ファイルを直接変更しません。

## 現在の制限

- Windows x64専用です。
- APNG、16-bit PNG、HEIC画像シーケンス、HDR HEICのトーンマッピングには未対応です。
- GIFアニメーションは先頭フレームだけを使用します。
- AI復元の速度と利用可否はGPU・ドライバー・画像サイズに左右されます。
- 3DプレビューはすべてのFBXマテリアルや独自シェーダーの再現を保証しません。

## トラブルシューティング

### AI機能を追加できない

通信を確認して再試行してください。VPN、プロキシ、セキュリティソフトがGitHub Releaseへの通信を遮断している場合があります。途中で失敗しても不完全なデータを有効化しません。

### AI復元を開始できない

GPUドライバーを更新し、Vulkan対応を確認してください。大きな画像で失敗する場合は「分割品質」を標準または低メモリへ下げます。

### FBXのテクスチャが見つからない

FBXとテクスチャを共通のフォルダー内へ置き、書き出し時のフォルダー構成を保ってください。必要に応じてBlenderから相対パスで書き出し直します。

## 開発

```powershell
npm install
npm run tauri -- dev
```

通常のビルドにはAIモデルを同梱しません。開発環境で事前取得する場合だけ `npm run prepare:ai` を使用します。

```powershell
npm run build
Set-Location src-tauri
cargo test
Set-Location ..
npm run tauri -- build
```
