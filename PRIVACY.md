# Be Asset Optimizer プライバシーポリシー

最終更新日: 2026年9月21日

Be Asset Optimizer（以下「本アプリ」）は、画像および3Dアセットを利用者のPC内で処理するデスクトップアプリです。

## 収集する情報

本アプリは、個人情報、利用状況、端末識別子、広告識別子、位置情報を開発者のサーバーへ収集または送信しません。アカウント登録、広告、アクセス解析、遠隔測定機能はありません。

## 利用者のファイル

利用者が選択した画像、FBX、GLBその他のファイルは、変換とプレビューのためにPC内でのみ読み取られます。入力ファイルおよび生成されたファイルを外部サービスへアップロードしません。元のファイルは、利用者が明示的に同じ保存先を選ばない限り直接変更しません。

## PC内に保存するデータ

本アプリは表示設定などのアプリ設定と処理結果をPC内に保存します。生成ファイルの保存先は利用者が選択できます。

## ネットワーク通信

通常の画像変換、ノーマルマップ生成、テクスチャアトラス作成および3Dプレビューはオフラインで実行されます。

AI復元機能およびモデルのダウンロード機能はありません。サポートリンクを開く場合、外部サイトにはそのサイトのプライバシーポリシーが適用されます。

## 第三者への提供

本アプリは利用者の個人情報を収集しないため、開発者から第三者への販売、共有または提供は行いません。

## データの管理

利用者が作成した変換結果は、利用者自身が通常のファイル操作で管理できます。旧版で追加したAIコンポーネントは自動削除されません。

## 変更

機能やデータの取り扱いが変わる場合、この文書を更新し、最終更新日を変更します。

## お問い合わせ

プライバシーに関するお問い合わせは、[GitHub Issues](https://github.com/studio-juh/be-asset-optimizer/issues)からご連絡ください。

# Be Asset Optimizer Privacy Policy

Last updated: September 21, 2026

Be Asset Optimizer (the “App”) is a desktop application that processes images and 3D assets locally on the user's PC.

## Information collection

The App does not collect or transmit personal information, usage data, device identifiers, advertising identifiers, or location data to the developer's servers. The App has no account registration, advertising, analytics, or telemetry.

## User files

Images, FBX, GLB, and other files selected by the user are read only for local conversion and preview. The App does not upload input files or generated files to external services. Source files are not modified directly unless the user explicitly chooses the same output destination.

## Data stored on the PC

The App stores application preferences and processing results locally. The user chooses where generated files are saved.

## Network access

Standard image conversion, normal-map generation, texture-atlas creation, and 3D preview run offline.

The App has no AI restoration or model download feature. External support websites have their own privacy policies.

## Sharing with third parties

Because the App does not collect personal information, the developer does not sell, share, or disclose user personal information to third parties.

## Data control

Users manage generated files through normal file-management operations. AI components installed by older versions are not automatically removed.

## Changes

If the App's features or data practices change, this policy will be updated and the date above will be revised.

## Contact

For privacy questions, contact the developer through [GitHub Issues](https://github.com/studio-juh/be-asset-optimizer/issues).
