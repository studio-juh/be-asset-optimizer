Be Asset Optimizer 0.6.1
Blender向け画像・3Dアセット最適化ツール

【動作環境】
Windows 10 / 11 64-bit
Microsoft Edge WebView2 Runtime
画面解像度 960 x 640以上

AI復元だけはVulkan対応GPUと最新のGPUドライバーが必要です。
初回に約61 MBをダウンロードし、約70 MBを保存します。
AI復元以外の機能はAIモデルや対応GPUなしで利用できます。

【セットアップ版】
Be Asset Optimizer_0.6.1_x64-setup.exe を実行し、画面の案内に従ってください。

【ポータブル版】
ZIPを展開し、Be Asset Optimizer.exe を起動してください。
移動するときはフォルダーごと移動してください。

【基本操作】
1. 上部のタブまたは「機能」メニューから機能を選びます。
2. ファイルを画面へドロップするか、Ctrl+Oで選択します。
3. 左側で出力先と設定を指定します。
4. 変換を開始します。
5. 完了した行の「開く」から出力を確認します。

元ファイルは上書きしません。
画像や3Dモデルは外部へアップロードしません。
ネットワーク通信はAIコンポーネントの追加時だけ使用します。

【対応形式】
画像入力: PNG / JPEG / JFIF / WebP / HEIC / HEIF / BMP / TIFF / GIF / TGA / DDS
画像出力: PNG / WebP / JPEG
3Dプレビュー: FBX / GLB

GIFは先頭フレームだけを使用します。
3Dプレビューは確認用で、モデルの編集や再出力は行いません。

【Windowsの警告について】
現在の配布物にはコード署名がありません。
Windowsの発行元確認やSmartScreenが表示される場合があります。
入手元とファイル名を確認したうえで実行してください。
